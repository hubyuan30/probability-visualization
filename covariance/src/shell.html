01 / INTUITION
先拆词

“协”是结伴，“方差”是波动

协方差就是把“偏离均值”这件事从一个人变成两个人：各自先找基准线，再把两个偏离乘起来。英文 co-variance 里，co- 是“共同”，variance 是“波动”；乘积的符号，就是它们这次是“同向”还是“反向”。

单个变量 D

方差 · 独自波动

D(X) = E[(X − EX)²]

只看 X 一个人：每次偏离均值多少，平方之后取平均。平方让正负偏离都算“波动大”，所以方差永远不小于 0。

自己跟自己比 · 量的是“散得开不开”
两个变量 Cov

协方差 · 结伴波动

Cov(X, Y) = E[(X − EX)(Y − EY)]

把 X 的偏离和 Y 的偏离乘在一起。同号 → 正贡献，异号 → 负贡献，再取平均。正负抵消得越多，协方差越接近 0。

同向为正 反向为负 · Cov(X,X)=D(X)
几何直觉

把每个点放进四个象限

以均值点 (EX, EY) 为原点。每个点都用一个乘积投票：横向偏离和纵向偏离同号就投“正”，异号就投“负”。

Ⅰ & Ⅲ · 同号 → dx·dy > 0 · 正贡献
Ⅱ & Ⅳ · 异号 → dx·dy < 0 · 负贡献

点云越偏向 Ⅰ / Ⅲ 两象限，协方差越正；越偏向 Ⅱ / Ⅳ，协方差越负。如果两边势均力敌，就会相互抵消。

“

方差：独自波动；协方差：结伴波动。

协方差 = 两个变量“共同偏离各自均值”的平均乘积。正负号说明方向，绝对值说明这种共同趋势的强弱（但会受量纲影响）。

04 / FORMULA
公式解剖

一行公式，四个动作

别急着背。把 Cov(X,Y) = E[(X−EX)(Y−EY)] 拆成四步，每一步都能在上一张图里找到对应。

主公式
Cov(X, Y) = E[ (X − EX)(Y − EY)]
先各自偏离均值，再把两个偏离相乘，最后对乘积取期望（平均）。
协方差衡量的不是“数值大小”，而是“偏离方向是否一致”。
  1. 01
    找两条基准线：EX 和 EY

    均值是“各自的地心”。协方差关心的是每个点相对自己均值偏了多少，而不是它的绝对大小。

  2. 02
    各算一个偏离：X−EX 与 Y−EY

    横向偏离告诉你 X 这次偏大还是偏小，纵向偏离描述 Y。正负号已经藏在里面了。

  3. 03
    把两个偏离相乘

    同号相乘为正：这次“一起偏大”或“一起偏小”；异号为负：一个偏大、一个偏小。乘积就是每个点的投票。

  4. 04
    E[·] 取期望

    把所有点的带符号乘积平均。正票多，协方差为正；负票多，协方差为负；势均力敌，就接近 0。

名字对上了

Cov(X, X) = D(X)

自己和自己“结伴”，乘积变成偏离的平方，平均起来正是方差。方差只是协方差的特例。

考试常用

Cov(aX+b, cY+d) = ac · Cov(X,Y)

加减常数只是整体平移，不改变偏离；乘常数会等比缩放偏离，两个缩放系数相乘。

和与差

D(X ± Y) = D(X) + D(Y) ± 2Cov(X,Y)

协方差就是两个变量相加时的“交叉项”。相互独立时它等于 0，方差才简单相加。

去掉量纲

ρ = Cov(X,Y) / (σXσY)

把协方差按两个标准差标准化，得到 [−1, 1] 之间的相关系数。ρ 只描述线性相关，不带单位。

Cov(X, Y) = E(XY) − EX · EY 等价的常用写法，很多计算题直接套它更快。
05 / TRAPS
三个常见误区

协方差会“骗人”的地方

它不是万能的相似度。协方差只抓线性趋势，还带着量纲，更不能告诉你谁导致谁。

最容易错

Cov = 0，不代表独立

协方差只抓“线性趋势”。下面这条 U 形关系是 Y = X² + 噪声：Y 明明由 X 决定，但左右两臂的正负贡献互相抵消，协方差接近 0。独立一定不相关，不相关却不一定独立。

Cov ≈ 0.00 r ≈ 0.00 但 Y 由 X 决定
Y = X² + 噪声
量纲陷阱

数值大 ≠ 关系强

把 X 的单位从“米”换成“厘米”，每个数乘 100，协方差也直接乘 100，但两个变量的关系一点没变强。这就是为什么要看 ρ。

06 / CHECK
自测

四道题，检验“真的懂了”

选一个答案，马上看解释。答错也没关系，回到上面的图里找线索，比背结论有用。

0 / 4
Q1

“当 X 比均值大时，Y 往往也比均值大”，这最直接对应下面哪一句？

为什么

同向偏离时，(X−EX)(Y−EY) 多为正，平均起来协方差就为正。协方差首先告诉你方向，而不是“谁一定跟着谁变”。

Q2

已知 Cov(X,Y) = 2，则 Cov(3X−1, −2Y+5) 等于？

为什么

平移不改变偏离，缩放系数要相乘：Cov(aX+b, cY+d) = ac·Cov(X,Y) = 3×(−2)×2 = −12。负号来自两个变量方向相反地缩放。

Q3

若 Cov(X,Y) = 0，下面哪句话最准确？

为什么

协方差只捕捉线性关系。Y = X² 就是反例：Cov ≈ 0，但 X 完全决定了 Y。独立 ⇒ 协方差为 0；协方差为 0 ⇏ 独立。

Q4

把 X 的单位从米换成厘米（数值 ×100），Y 不变。下面会发生什么？

为什么

Cov(100X, Y) = 100·Cov(X,Y)，协方差带量纲；ρ 已经除以 σXσY，单位被约掉，所以保持不变。
